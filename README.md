# Práctica 1: Machine Learning aplicado a Robótica

## Estudiante
Ing. Fabián Pesántez

## Asignatura
Inteligencia Artificial

## Descripción

Desarrollo de un pipeline completo de Machine Learning utilizando datos reales de navegación de un robot móvil.

Se implementarán modelos supervisados y no supervisados para analizar comportamientos de navegación mediante sensores ultrasónicos.

## Dataset

Wall-Following Robot Navigation Data (UCI)

## Objetivo

Crear un proyecto reproducible utilizando Python, análisis de datos, entrenamiento de modelos y evaluación mediante métricas.
